# Smart Public Transport Advisor

Topic B project for COMP1110, Semester 2 2025-2026.

This repository contains a Python public-transport journey planner and a Next.js map frontend. The Python program models Hong Kong transport as a directed graph, generates candidate journeys with depth-limited DFS, and ranks them by cheapest, fastest, or fewest hops.

## Project Layout

- `main.py`: terminal menu for journey planning, stop listing, network map display, case studies, and help
- `network.py`: `Stop`, `Segment`, and `Network` classes plus DFS path search
- `journey.py`: journey totals, hop counting, realtime adjustment, and ranking by preference
- `file_io.py`: CSV loading/saving with validation for missing, empty, malformed, and inconsistent files
- `check.py`: live transport helpers for geocoding, MTR ETA, KMB ETA, nearby-stop lookup, and TDAS traffic data
- `backend_api.py`: HTTP API used by the frontend (`/health`, `/network`, `/summary`, `/eta`, `/plan`)
- `ui.py`: terminal display helpers
- `data/stops.csv`: 15 stop records with IDs, names, coordinates, and available lines
- `data/segments.csv`: 54 directed transport segments with mode, duration, and cost
- `data/last_results.txt`: latest saved route output generated by the program
- `tests/`: unit and stress tests
- `frontend/`: Next.js frontend for map-based route planning and live ETA display
- `CASE_STUDIES.md`: four realistic Topic B scenarios
- `GUIDELINE_COVERAGE.md`: requirement-by-requirement coverage notes
- `AI_usage.md`: AI usage disclosure log

## Data Format

`data/stops.csv`

```csv
id,name,latitude,longitude,lines
S01,Central,22.2819,114.1584,MTR;Ferry;Tram;Bus
```

`data/segments.csv`

```csv
seg_id,from_stop,to_stop,mode,duration,cost
SEG01,S01,S02,MTR,2,5.2
```

Each segment is directed and must reference existing stop IDs. Duration is in minutes and cost is in HKD. File loading reports clear errors for empty files, missing columns, duplicate IDs, non-numeric durations/costs, negative values, and unknown stop references.

## Run The Terminal Program

```bash
python main.py
```

Menu options:

- plan a journey
- view all stops
- view a text network map
- run four case studies
- view help/about
- quit

## Run The Python Backend

```bash
python backend_api.py
```

Default URL: `http://127.0.0.1:8000`

Endpoints:

- `GET /health`
- `GET /network`
- `GET /summary`
- `GET /eta?stopId=S01`
- `POST /plan`

`/network` returns stops, segments, and summary metrics. `/summary` returns only the summary metrics.

## Run The Frontend Locally

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

The frontend calls `/api/backend/...`, which proxies to the Python backend.

## Live Data Feature

The project includes live data support:

- MTR ETA lookup
- KMB ETA lookup
- nearby stop matching
- geocoding for user-entered Hong Kong locations
- TDAS traffic speed lookup for bus/minibus time adjustment

If external APIs are unavailable, the planner falls back to static timing assumptions.

## Topic B Coverage

- Defines stops, segments, costs, durations, journeys, and preference modes.
- Uses a hand-crafted network with 15 stops and 54 directed segments.
- Provides a text menu in `main.py`.
- Loads network data from CSV files.
- Handles missing, empty, malformed, and inconsistent data files.
- Validates unknown stops, same origin/destination, menu choices, and preference modes.
- Shows a network summary with stop count, segment count, average commute time, and average cost.
- Generates candidate journeys using DFS with a depth limit.
- Ranks routes by cost, time, and hop count.
- Provides route output with cost, time, hop count, stop sequence, and mode sequence.
- Includes four case studies and an edge-case stress test suite.
